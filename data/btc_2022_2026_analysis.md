## 3. 단타(Scalping) 기준 진단 및 조정 제안

### [진단 1] SPIKE_THRESHOLD 0.8% — 시장 적응 부재

**현재:** 고정값 0.8% (5분 내 가격변동 감지 기준)

| 연도 | 4h 0.8%+ | 판정 | 설명 |
|------|---------|------|------|
| 2022 | 28.5% | ✅ 적절 | 충분한 기회 |
| 2023 | 17.9% | ❌ 높음 | 기회 부족 |
| 2024 | 27.1% | ✅ 적절 | |
| 2025 | 19.3% | ❌ 높음 | 기회 부족 |
| 2026 | 26.9% | ✅ 적절 | |

저변동 시장(2023, 2025)에서 0.8%가 너무 높아 기회를 놓침.

**제안: 적응형 spike threshold**
```python
# 최근 24h ATR 기반 동적 조절
SPIKE_THRESHOLD = max(0.5, min(1.0, ATR_24h * 0.6))

# 예시:
# 고변동(ATR 2.0%) → threshold 1.0%
# 중변동(ATR 1.3%) → threshold 0.78%
# 저변동(ATR 0.8%) → threshold 0.50%
```

### [진단 2] STOP_LOSS 25% / TAKE_PROFIT 30% — 비현실적 (Critical!)

**현재:** SHORT_TERM_STOP_LOSS = 0.25 (25%), SHORT_TERM_TAKE_PROFIT = 0.30 (30%)

이건 단타가 아니다. 15분 보유 기준으로:
- 2025년 15분 평균 변동: ~0.15~0.30%
- 15분 내 25% 손실 확률 = 사실상 0%
- 실질적으로 **"무손절 + 시간 손절(15분)"만 작동 중**

**5년간 실제 15분 변동폭:**

| 시장 상태 | 15분 평균 변동 | 15분 최대 변동 |
|----------|-------------|-------------|
| 저변동(2023) | ~0.10% | ~1.0% |
| 중변동(2024) | ~0.15% | ~2.0% |
| 고변동(2022) | ~0.20% | ~3.0% |
| 극고변동(2026-02) | ~0.25% | ~4.0% |

**제안: 실제 단타 손절/익절**
```python
# 방법 1: 고정값 (즉시 적용)
SHORT_TERM_STOP_LOSS = 0.004   # 0.4%
SHORT_TERM_TAKE_PROFIT = 0.006  # 0.6% (R:R = 1:1.5)

# 방법 2: ATR 연동 (권장)
STOP_LOSS = ATR_15m * 1.5      # ATR의 1.5배
TAKE_PROFIT = ATR_15m * 2.0    # ATR의 2.0배 (R:R = 1:1.33)

# 수수료: 왕복 0.1% → 최소 순익 0.15% 필요
```

### [진단 3] WHALE_THRESHOLD 2억원 — 가격 변동 미반영

| 시점 | BTC 가격 | 2억원 = | 의미 |
|------|---------|---------|------|
| 2022 중반 | 3천만 | 6.7 BTC | 대형 거래 |
| 2024 말 | 1.4억 | 1.4 BTC | **소형 거래** |
| 2025 말 | 1.6억 | 1.25 BTC | **의미 없음** |

가격이 5배 올랐는데 고래 기준이 그대로 → 잡음(noise) 거래를 고래로 오인.

**제안: BTC 수량 기반 전환**
```python
# 방법 1: BTC 수량 고정
WHALE_THRESHOLD_BTC = 5.0  # 약 5~8억원 (현 시세)

# 방법 2: 24h 거래량 대비 비율
WHALE_THRESHOLD = daily_volume * 0.001  # 일 거래량의 0.1%
```

## 5. 결론

### 핵심 발견

1. **단타 파라미터가 실제 스캘핑과 불일치:** 25%/30% 손절/익절은 중장기 스윙 기준이지 15분 단타가 아님. 실질적으로 시간 손절(15분)만 작동 중.

2. **시장 적응력 부재:** 2023/2025 저변동장에서는 0.8% spike threshold가 너무 높아 대부분 기회를 놓치고, 2022/2026 고변동장에서는 손절이 없어 큰 손실 발생.

3. **하락 추세 매수 편향:** 5년간 매수:매도 = 14:1 비율. 하락장에서도 계속 매수하여 구조적 손실(-47.8% in 2022, -29.9% in 2025) 발생. 이것이 B&H 대비 -111.5%p 언더퍼포먼스의 최대 원인.

4. **매크로 연결 부재:** 금리인상기(2022)에 매수 단타, 금리인하기(2023-2024)에 불필요한 단타, 불확실기(2025-2026)에 무방향 단타 → 모든 시기에서 차선 전략.

### 방향

**"적응형 단타 시스템"으로의 전환이 필요**

시장 레짐(bull/bear/sideways)을 먼저 판단하고, 레짐에 맞는 단타 파라미터를 동적으로 적용해야 한다.

| 레짐 | SPIKE | SL/TP | MAX_HOLD | 방향 | 빈도 |
|------|-------|-------|---------|------|------|
| Bull (상승) | 0.6~0.8% | 0.3/0.5% | 15분 | 매수 80% | 낮음 (보유 우선) |
| Bear (하락) | 0.8~1.0% | 0.4/0.6% | 10분 | 매도 70% | 중간 |
| Sideways (횡보) | 0.5~0.6% | 0.3/0.4% | 20분 | 양방향 50:50 | 높음 |
| Crisis (급락) | 1.2%+ | 0.5/0.8% | 8분 | 매도 only | 선별적 |

이 보고서의 ❶❷❸을 즉시 적용하면 가장 큰 구조적 문제(무손절, 기회 놓침)를 해결할 수 있다.
