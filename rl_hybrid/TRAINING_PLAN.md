## 향후 개선 방향

### 1. 거래 빈도 감소
- 현재 268회 → 목표 50~100회
- action threshold 도입: |action_change| > 0.2 이상만 거래 실행
- 거래당 수수료 구조를 보상에 더 강하게 반영

### 2. 외부 데이터 통합
- Supabase에 저장된 실제 FGI/뉴스/고래 데이터를 훈련에 반영
- 42차원 중 상수인 ~15차원을 실제 히스토리컬 값으로 대체
- 이를 통해 시장 심리/외부 이벤트 학습 가능

### 3. 멀티 타임프레임
- 1h 모델(현재) + 4h 모델을 앙상블
- 1h: 진입/퇴출 타이밍, 4h: 트렌드 방향

### 4. 주간 자동 재학습
- `weekly_retrain.py` 활용하여 매주 최신 데이터로 업데이트
- ModelRegistry로 버전 관리 + 성능 저하 시 자동 롤백
