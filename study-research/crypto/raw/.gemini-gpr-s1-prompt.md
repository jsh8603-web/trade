# Research: Geopolitical Risk (GPR) → Cryptocurrency / Bitcoin Volatility

Caldara-Iacoviello (2022 AER) GPR Index 가 비트코인/암호화폐의 **변동성(volatility)** 에 미치는 영향에 관한 **동료심사(peer-reviewed) 학술 문헌**을 조사해줘. 우리는 GPR 을 BTC forward realized volatility 예측의 throttle-overlay 신호 후보로 검토 중이고, ★핵심 결정 게이트는 "GPR 이 VIX(equity implied vol)에 흡수되는가, 아니면 VIX 통제 후에도 독립 증분이 있는가" 다.

## 핵심 질문 (각각 동료심사 근거 + 정량 magnitude + 표본기간 명시)

1. **메커니즘**: GPR(지정학 위험) 상승이 BTC/crypto 변동성을 (a) 동시적으로 높이는가 (b) 선행 예측하는가? 경로(safe-haven flow / risk-off deleveraging / liquidity)? 부호와 magnitude.

2. **★VIX 직교성 (생사 게이트)**: GPR 과 VIX 를 동시에 넣었을 때 crypto 변동성에서 GPR 의 독립 증분이 살아남는 동료심사 증거가 있는가? GPR 과 VIX 의 상관은 보통 얼마인가? GPR 이 VIX 에 흡수된다는(redundant) 연구 vs 독립 채널이라는 연구 양쪽 다.

3. **시대성(epoch)**: 2017-2022(초기, BTC-macro orthogonal, Benigno-Rosa) vs 2023+ 기관화 이후 GPR-crypto 변동성 연동이 출현/강화됐는가? 표본기간별 차이.

4. **regime 의존 / tail 비대칭**: GPR-crypto vol 전이가 high-vol/risk-off regime 또는 tail(극단)에서만 강한 비대칭인가? quantile/Markov-switching 증거.

5. **GPR_ACT(행위) vs GPR_THREAT(위협) 분해**: Caldara-Iacoviello sub-index 가 crypto 에 차등 적용되는 동료심사 사례?

6. **BTC vs Gold 대조**: gold 에서 GPR 은 safe-haven tail-amplified(q90/OLS 5.91×) 인데, BTC 는 'digital gold' 가설처럼 GPR 에 양(+) safe-haven 반응인가, 아니면 risk-asset 처럼 음(−)/변동성↑ 반응인가? 상반된 증거 정리.
