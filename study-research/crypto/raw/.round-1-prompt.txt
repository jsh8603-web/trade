[①이론 수집방향]
코인 가격결정을 깊이 이해하려면 무슨 이론·교과서·논문·리포트·OSS 를 봐야 하나? 5~10개 핵심 자료를 제안하고, 각 자료가 어떤 driver 를 설명하는지 1줄로. 특히 다음 5개 채널을 어떻게 다룰지:
(i) 펀더멘털 없는 자산의 가치평가 이론 (MVRV/NUPL/SOPR realized-value 기반 cycle indicator)
(ii) 공급 schedule 효과 (halving cycle 4기, 통계적 검정력 N=4 한계 포함)
(iii) 거시 유동성 transmission (real rate·DXY·M2·stablecoin supply)
(iv) 시장 미시구조 (perpetual funding cascade, BTC dominance rotation, alt-season)
(v) 'digital gold' vs 'risk asset' 디커플 시점 (BTC spot ETF 2024 승인 후 변화, 기관 채택)

[②이론 검증방향]
위 이론들을 우리 보유 데이터로 어떻게 시계열 검증하나? 구체적 방법론을 제시:
- 어떤 partial-corr edge 가 적용 가능한가 (예: MVRV ⊥ price | FGI, dominance ⊥ price | macro real_rate 등)
- regime 분해 단위 (FGI 5단계 / halving 4-phase / macro risk-on·off 의 조합 belief)
- Rank-IC 산출 단위 (BTC 단일 vs 멀티코인 cross-section vs sleeve aggregate)
- 검정력 한계 (halving 4 사이클 N 문제, MVRV 시계열 길이, FGI 일별/이벤트별)
- forward return 정의 (horizon 7d / 30d / 90d 중 어떤 가설은 어떤 horizon)
- 무lookahead 검증 방법 (knowable_from 사용)

[③핵심 가설 초안 — 반증조건 포함]
위 driver 중 검증가능한 핵심 가설 5~8개를 다음 형식으로 제시:
- 가설 텍스트: "<driver> → <price 영향> in <regime/조건>"
- 반증조건: "<어떤 통계가 어떻게 나오면 거부> (예: hit rate < 0.5 binomial p>0.05, Rank-IC e-CUSUM 단측 붕괴 임계, partial-corr 추정치 0 포함 95% CI)"
- partial-corr edge 분류: direct / common_cause / undetermined + conditioning_set
- prior_sign: pos / neg / unsigned
- prior_strength: 0~1
- forward return horizon
- 우리 시스템 어느 코드 경로에서 신호 발생/누적 (예: instrument_source.run_mvrv_closed_loop, weight_falsification.score_ic_breakdown_eprocess 등)
