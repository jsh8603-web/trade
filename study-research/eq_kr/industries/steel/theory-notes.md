## §0. 핵심 산업 특성 (cyclical archetype, ★초자산집약 장치산업)

철강(특히 고로 일관제철)은 **강 cyclical + 초자산집약(capital-intensive) 장치산업**. 다음 5 특성이 신호 부호·conditional 구조를 결정:

1. **초자산집약 (★capex 가설 핵심)**: 고로(blast furnace)·제강·압연 설비 = 수조원 단위 고정자산. 유형자산/총자산 비율이 전 산업 최고 수준(POSCO/현대제철 PPE/Assets ≈ 0.4-0.5, 반도체와 함께 최고). 증설 사이클 = capex 대규모 → 가동 후 감가상각·고정비 부담 → 다운사이클에 적자 전환.
2. **중국 의존 cyclical**: 글로벌 조강 생산의 ~55%가 중국. 중국 부동산·인프라 수요 + 중국 증설/감산 정책이 글로벌 철강 가격(열연·후판)을 결정 → 한국 철강사 spread(판가-원가) 좌우.
3. **원가 = 철광석·원료탄 (수입 100%)**: 한국 고로사는 철광석·원료탄 전량 수입(호주·브라질). 철광석 가격(Platts 62% Fe) 상승 = 원가 압박. 판가 전가 시차(lag) → margin squeeze cycle.
4. **전방 = 자동차·건설·조선**: 자동차 강판(현대제철-현대차 captive), 건설용 봉형강(철근), 조선용 후판이 전방 수요. 전방 cycle(자동차 SAAR / 건설 착공 / 조선 수주)이 철강 수요 선행.
5. **저성장·과잉공급 산업 (value/배당 특성)**: 구조적 과잉공급 + 저성장 → 멀티플 낮음(저PBR·고배당). cyclical 가치주 성격. 단 다운사이클 적자 → PER 왜곡(peak-EPS trap 반대로 trough-EPS 무의미).

## §1. 메커니즘별 부호 사전확약 (★측정 前 이론 동결)

### M1. ★★capex_ratio / ppe_yoy → asset growth anomaly (음) [dispatch 최우선]

- **메커니즘**: 자산성장 anomaly = 유형자산·총자산을 공격적으로 늘린(증설) 기업이 forward return 낮음. (a) 과잉투자(empire building, 경영진 agency) (b) cyclical 정점에 증설 결정 → 다운사이클 진입 시 과잉설비·고정비 부담 (c) 투자자 over-extrapolation(현 호황 연장 기대). ★철강 = 초자산집약이라 **이 anomaly 가 가장 선명하게 발현될 prior**(고로 증설 = 수조원, 사이클 정점 증설→과잉공급 되돌림).
- **부호 사전확약**:
  - **capex_ratio (유형자산/총자산): ★음(-)** — 高 capex 종목 → forward 약. = asset growth anomaly.
  - **ppe_yoy (유형자산 증가율): ★음(-)** — 증설 가속 종목 → forward 약 (cycle 정점 증설 되돌림).
- **출처**: Cooper, Gulen & Schill (2008) "Asset Growth and the Cross-Section of Stock Returns" JF [총자산 성장률 anomaly, 가장 강력한 cross-sectional predictor 중 하나] / Titman, Wei & Xie (2004) "Capital Investments and Stock Returns" JFQA [abnormal capital investment → 음의 forward return] / Lipson-Mortal-Schill (2011) "What Explains the Asset Growth Effect?".
- **자동차 anchor 연계**: dispatch = "자동차 capex_ratio = structural_prior_high_confidence(음)". 철강 = 자산집약 더 극단 → 동일 prior 더 강하게 적용. **자산집약 4섹터(화학/정유/조선/철강) capex 일반화 = 메인 종합 대상**.
- **반증조건(falsifier)**: capex_ratio IC ≥ +0.03 (高 capex → forward 강) → asset growth anomaly 가설 기각 (철강은 capex = 미래 capacity = 성장 신호로 해석되는 역가설).

### M2. valuation: PBR(음, 작동) vs PER(왜곡, trough/peak-EPS trap)

- **메커니즘**:
  - PBR robust: 철강 = 자산집약 → BPS(축적 자본 stock)가 안정적 기준점. cyclical 이익 변동에 둔감. 저PBR(청산가치 대비 저평가) = value premium. ★단 철강 = 구조적 저PBR 산업(P/B<1 다수) → cross-sectional 분산 작을 수 있음.
  - PER 왜곡: 철강 cyclical = (a) 정점 EPS 高→PER 低 착시(peak-EPS trap, 반도체 동형) (b) 다운사이클 적자→PER 무의미(trough). 양방향 왜곡 → PER cross-sectional 무효 prior.
- **부호 사전확약**:
  - 저PBR(낮은 z) → forward 양 = **IC 음(-)** (value premium).
  - 저PER: cyclical 왜곡 → **비유의/무효 prior** (peak/trough-EPS).
  - PBR 이 PER 보다 robust (반도체·자동차 동형 = cyclical 공통).
- **출처**: Asness, Frazzini & Pedersen "Quality Minus Junk" RAS (cyclical 정점이익 저품질 → book-value 우월) / Fama-French value premium (HML) / Lazard "P/E a Poor Measure for Cyclical Stocks".
- **반증조건**: PBR IC |ρ|<0.03 전 horizon → value premium 무효 / PER IC 유의(|ρ|>0.05 + p<0.05) → cyclical EPS 왜곡 가설 기각.

### M3. 가격 momentum → cyclical reversal (장기 음) vs continuation (중기 양?)

- **메커니즘**: cyclical 산업 12M 누적수익 최강 시점 = 사이클 정점 근처 → 공급과잉·spread 둔화로 되돌림(momentum crash 동형). ★단 철강 = 반도체보다 cycle 완만(중국 정책 driven, ASP hyper-cycle 아님) → reversal 강도 약할 수 있음. 중기(3-6M)는 spread 모멘텀 continuation 가능.
- **부호 사전확약**:
  - 12M+ long-horizon momentum: **음(-) reversal** (반도체 동형, cyclical 정점 되돌림). ★단 철강 cycle 완만 → 강도 약 prior.
  - 3-6M: 양(+) continuation 가능(spread/판가 연속성). horizon 따라 부호 전환 가능.
- **출처**: Daniel & Moskowitz (2016) "Momentum Crashes" JFE / Grinblatt & Moskowitz (2004) JF (industry-relative momentum).
- **반증조건**: 12M momentum IC ≥ +0.03 (continuation) → cyclical reversal 가설 기각.

### M4. 중국 철강 수요·철광석 spread → 산업 cycle timing (forward 약, contemporaneous 동행)

- **메커니즘**:
  - 중국 조강생산 yoy ↑ = 글로벌 수요 강 → 철강 가격·spread ↑ → 한국 철강사 이익 양. ★단 중국 증설 → 공급과잉 → 가격 하락의 양면성(수요 vs 공급).
  - 철광석 가격 ↑ = 원가 압박(판가 전가 lag) → 단기 margin squeeze 음. 단 가격 상승 자체가 수요 강세 신호(동행 양)일 수도 = 부호 모호.
  - 후판/열연 가격 = 한국 철강사 ASP 직접. ★이들은 **산업 공통 시계열**(timing) = cross-sectional 신호 부적합. regime conditioning 변수로 활용(반도체 DRAM ASP 동형).
- **부호 사전확약**:
  - 중국 조강생산 yoy → 산업 forward 양(+) 약 prior (동행 dominant, forward 예측력 약).
  - 철광석 가격 yoy → 산업 forward 음(-) 약 prior (원가 압박) — 단 수요-동행 교란.
  - ★cross-sectional 신호 아님 = regime/timing 변수.
- **출처**: 산업 cycle 이론 (commodity-driven sector) / frame v3 §M.3 (산업 cycle = 동시 동조, forward 약) / 반도체 dram_asp_ppi 측정 결과(timing forward 비유의) 동형 prior.
- **반증조건**: 산업 forward IC |ρ|>0.10 + p<0.05 (강 forward 예측) → 동행 dominant 가설 기각.

### M5. 외국인 flow regime → conditional (flow regime × 팩터 IC)

- **메커니즘**: 외국인 = POSCO홀딩스 등 대형 철강주 보유. ★conditional: passive(ETF) 자금 강할 때 = 시장전체 이동 → 개별 종목신호(value/momentum) IC 약화. ★단 철강 = 외국인 비중 반도체보다 낮음(반도체 50%+ vs 철강 ~30%) → flow conditional 효과 약 prior.
- **부호 사전확약**:
  - 외국인 순매수 강도 → forward 1-3M 양(+) 약 prior.
  - ★conditional: 외국인 강매수 regime 에서 value/momentum IC 감소(passive 지배) — 약 prior.
- **출처**: Choe, Kho & Stulz (2005) JFQA / frame 신지표#4 (외국인 flow regime).
- **반증조건**: regime별 IC 차 <0.02 → conditional 무효.

### M6. quality/배당 (저변동·고배당, asset_stable 성격 보조)

- **메커니즘**: 철강 = 저성장·고배당 산업(POSCO/현대제철 배당수익률 高). 다운사이클 방어 = 고배당·저부채 종목 선호 가능. 단 cyclical 본질이라 배당 안정성 약(적자 시 배당 컷).
- **부호 사전확약**: 배당수익률/저변동 → forward 양(+) 약 prior (defensive demand). ★측정 우선순위 낮음(cyclical 본질, 데이터 = DART 배당 추가 필요).
- **출처**: Frazzini-Pedersen "Betting Against Beta" / QMJ.
- **반증조건**: 배당/저변동 IC 비유의 → defensive 가설 기각.

## §3. archetype 사전선언 (PIT attestation, §M.5 ex-post 금지)

- **archetype = cyclical** (자산집약 commodity 장치산업). primary_metric = **PBR** (peak/trough-EPS 왜곡으로 PER 무효 prior, ev_ebitda 차선).
- valid_from = 2019-01-01 (측정 구간 시작, 철강은 구조적 cyclical 일관 = transition 없음, ex-post hazard 낮음).
- secondary = asset_stable (배당/저변동 보조, prob ~0.2) — 저성장 고배당 성격.
- ★실측 검증 대상: momentum 부호 = 음(reversal) 이면 cyclical 지지 (battery 양과 반대). capex_ratio 음이면 asset growth anomaly = cyclical 자산집약 정합.

## §4. ★capex 일반화 가설 검증 설계 (dispatch 최우선)

dispatch ★★ = "철강 cycle 정점 증설→과잉공급 되돌림 가설". 검증 방법:
1. **cross-sectional**: capex_ratio(유형/총자산) + ppe_yoy 횡단면 z → forward IC (음 prior). measure_fundamentals_cycle.py 미러(반도체 동일 코드, prior 음).
2. **regime conditional**: 다운사이클(Macro Slowdown / 철광석 高) regime 에서 asset growth anomaly 증폭 가설.
3. **walk-forward OOS**: IS 2019-22 / OOS 2023-26 부호 유지 → tentative 이상.
4. ★**자동차 결과 대조**: 자동차 capex_ratio prior(음) = high_confidence. 철강에서 재현되면 자산집약 4섹터 일반화 1보. 반증(양)이면 산업 특수성(철강 capex = capacity 성장 신호?) 보고.

★단 철강 universe 협소(23종) = small-breadth → cross-sectional IC magnitude 과대 위험(frame §M.12 small-n haircut). breadth-adjusted IR 병기 의무.
