## §2. 산업 cycle 이론 (theory-notes.md 후속 정독)

### 2.1 ★growth archetype prior + momentum 부호 (team-lead 핵심 질문)

team-lead 지시 = "성장주(growth) archetype = battery 동형(momentum continuation 가능성) → momentum 부호 = battery 양 continuation vs 반도체 음 reversal 어느 쪽인지 ★데이터 판정".

- **growth prior (사전 가설)**: 성장주는 실적 성장 모멘텀이 주가 모멘텀으로 이어진다 → momentum continuation(양, battery 동형) 가설.
- **반례 가설 (event_driven)**: 게임주 비중 큼 → 신작 기대 급등(buy-the-rumor) 후 출시 실망 급락(sell-the-news) = ★momentum reversal(음) 가능성. 인터넷도 2021 플랫폼 버블→2022 폭락 = 큰 진폭 reversal 환경.
- ★**데이터 판정 (사전확약 후 측정)**: momentum 부호를 측정으로 결정. continuation(양)이면 battery 동형 growth, reversal(음)이면 cyclical/event-driven peak 되돌림.

### 2.2 인터넷 광고 cycle

- NAVER/카카오 매출 = 검색광고·디스플레이광고 + 커머스 수수료 + 핀테크/콘텐츠. 광고경기 = 거시 소비·기업 마케팅 예산에 후행.
- 2021 = 코로나 비대면 수혜 + 저금리 플랫폼 멀티플 버블 (NAVER 46만원/카카오 17만원 peak). 2022 = 금리인상 → 성장주 멀티플 압축 → 70%+ 폭락.
- 2023-26 = AI 검색(하이퍼클로바X)·광고 회복 + 커머스 경쟁(쿠팡/알리). 멀티플 정상화.
- 이론 출처: 증권사 인터넷 in-depth (미래에셋/삼성증권 NAVER·카카오 커버리지), 메타/알파벳 광고 cycle 학술.

### 2.3 게임 cycle (event_driven, ★신작 dominant)

- 게임주 = 신작 출시·흥행이 실적·주가 최대 driver. 크래프톤(배그/인조이), 엔씨(리니지·TL), 넷마블(다중IP), 펄어비스(검은사막·붉은사막).
- ★주가-실적 비대칭: 신작 기대감에 선반영 급등 → 출시 후 매출 확인되면 차익실현(sell-the-news) = momentum reversal 메커니즘.
- 2021 = 메타버스/P2E(위메이드 위믹스) 버블 → 2022-23 P2E 규제·붕괴. 엔씨 리니지 매출 정점→하락. = 큰 진폭 reversal 환경.
- 2024-25 = 신작 부재 구간 후 2025 크래프톤 인조이·엔씨 신작 기대. 글로벌 흥행(배그 PUBG) 안정성 차등.

### 2.4 SaaS/SW cycle (compounder + AI 수혜)

- 삼성SDS(클라우드·물류 SCL), 더존비즈온(ERP 구독 전환), 안랩(보안). B2B 구독 ARR = 가장 안정적 성장.
- AI capex 수혜: hyperscaler(AWS/Azure/GCP) capex yoy → 클라우드 인프라·AI SW 수요. 한국 SaaS = 간접 수혜.
- 셀바스AI·이스트소프트 = AI 직접 테마(주가 변동성 큼). 한컴 = AI 오피스.

### 2.5 거시 노출 (성장주 = 금리·달러 민감)

- ★성장주 = 듀레이션 긴 자산 → 금리(할인율) 민감. 금리인상기(2022) = 멀티플 압축 폭락, 금리인하기 = 멀티플 회복.
- USDKRW: 게임·인터넷 해외매출 비중 차등(크래프톤·펄어비스 글로벌 비중 高 = 원화약세 수혜 / 내수 인터넷 = 중립).
- 외국인 flow: NAVER/카카오 외국인 비중 높음 → flow regime 민감.
- VIX/risk-off: 성장주 = 고베타 → risk-off 시 약세 (bio 동형).

## §4. 핵심 가설 (부호 사전확약 = one-sided pre-commit, 측정 前 동결)

### H1. ★momentum 부호 = continuation(양) vs reversal(음) — growth archetype 판정 (team-lead 핵심)
- **메커니즘**: growth prior = 실적 성장 모멘텀 → 주가 continuation(양, battery 동형). 반례 = 게임 event_driven buy-the-rumor → reversal(음).
- **사전확약**: ★one-sided 미고정 (양/음 둘 다 경제동기 있음) → **부호 자체가 측정 대상**(archetype 판별). |IC|>0.05 + CI 0배제 시 유효.
- **반증조건**: |IC| < 0.03 전 horizon → momentum 무신호 (archetype 미판별).

### H2. valuation PBR/PER 횡단면 (★게임 PER 무효 가능 = event_driven/적자)
- **메커니즘**: 성장주 value premium 약 prior(성장주는 고멀티플 정당). ★게임 적자·턴어라운드 多(엔씨/넷마블/펄어비스 2022-24 적자) → PER 무효(bio 동형 event_driven). PBR 도 SW 무형자산 비중 커 book 왜곡 가능.
- **사전확약**: PER cross-sectional |IC| < 0.05 (무효 prior). PBR = 약 음 또는 무효.
- **반증조건**: PER |IC| > 0.08 + BY 생존 → value premium 작동 (성장주에도).

### H3. 금리(rate) 민감 = 성장주 듀레이션 (공통인자, contemporaneous)
- **메커니즘**: 성장주 = 긴 듀레이션 → 금리 상승 시 멀티플 압축 약세. β_rate < 0 prior.
- **측정**: aitech eq-weight 월수익 ~ 10Y Δ contemporaneous β (HAC).
- **반증조건**: β_rate ≥ 0 OR 비유의 → 금리 민감 가설 기각.

### H4. VIX/risk-off 민감 = 고베타 (공통인자)
- **메커니즘**: 성장주 고베타 → risk-off(VIX↑) 시 약세. β_VIX < 0 prior (수익 기준).
- **반증조건**: β_VIX ≥ 0 OR 비유의.

### H5. USDKRW 노출 = 글로벌 게임 수혜 (방향 불명, sub-cluster 차등)
- **메커니즘**: 게임 글로벌 비중 高(크래프톤/펄어비스) → 원화약세 수혜(+). 내수 인터넷 = 중립. → 산업 평균 β 약/혼재 prior.
- **반증조건**: β_dollar 강한 부호 + 유의 (예상은 약/혼재).

### H6. conditional IC = regime 따라 신호 발현 (dispatch 원의도 본체)
- **메커니즘**: momentum/valuation IC 가 KRW/flow/macro regime 따라 증폭·반전. 특히 ★성장주 = 금리·flow regime 강민감 → regime conditioning 효과 클 prior.
- **측정**: measure_conditional.py 36셀 단일축 + family_2 interaction. rejected 박제 前 family_2 의무(frame A-5).
- **반증조건**: 전 regime cell 부호 일관 + interaction 비유의 → conditional 효과 없음.

### H7. ★sub-cluster 부호 cancel 점검 (frame A-4)
- **메커니즘**: internet/game/saas 펀더멘털 driver 이질 → 채택 신호 IC 부호가 cluster 간 cancel 가능(예: game reversal 강 vs saas 무신호).
- **측정**: 채택 신호(momentum/PBR) IC 를 sub-cluster 별 측정 → 부호 점검.
- **반증조건**: 한 cluster 정반대 부호로 cancel → 분리 트리거 + team-lead 보고.

### H8. R&D/무형자산 = SW 성장 proxy (DART, Layer 1)
- **메커니즘**: SW/게임 = R&D·개발비(무형자산) 집약. R&D/자산 高 → 성장 종목 prox → forward outperform(양 prior, growth).
