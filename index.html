비트랑 (Bit-Rang)

비트랑은 파이썬의 규칙 기반 엔진, LLM 비정형 데이터 분석, 그리고 강화 학습(RL)이 결합된 하이브리드 자동 매매 에코시스템입니다. 장애 발생 시 인공지능이 스스로를 치료하는 '자가 치유' 능력을 핵심으로 합니다.

시스템 설정 가이드 (Setup)

1

의존성 패키지 설치

터미널에서 아래 명령어를 실행하여 필수 라이브러리를 설치합니다.

Bash
pip install -r requirements.txt
playwright install
2

환경 변수 설정 (.env)

루트 폴더에 .env 파일을 생성하고 다음 필수 항목을 입력합니다.

.env
UPBIT_ACCESS_KEY=your_access_key
UPBIT_SECRET_KEY=your_secret_key
GEMINI_API_KEY=your_ai_key
SUPABASE_URL=your_db_url
SUPABASE_SERVICE_ROLE_KEY=your_service_key
DRY_RUN=true # 실전 매매시 false로 변경
3

분석 엔진 실행

준비가 완료되면 분석 및 매매 루프를 가동합니다.

Shell
bash run_analysis.sh

운영 아키텍처 (Architecture)

비트랑은 단순한 매매 봇이 아닙니다. 규칙과 지능이 상호 작용하는 유기체입니다.

                        graph TD
                            A[External Data] --> B{Discovery Engine}
                            B --> C[deterministic Rules]
                            B --> D[LLM Intelligence]
                            C & D --> E[Decision Blender]
                            E --> F[Execution]
                            F --> G[(Supabase DB)]
                            G --> H[RL Trainer]
                            H -->|Optimize Weights| E
                            I[Lifeline Agent] -.->|Monitor & Heal| B

강화 학습 및 지능 진화 (RL)

비트랑은 시간이 지남에 따라 더 똑똑해집니다. 모든 매매 데이터(성공, 실패, 보류)는 학습의 재료가 됩니다.

단계 설명
데이터 기록 매매 시점의 모든 시장 정보(심리, 온체인, 지표)를 DB에 저장
보상 계산 PnL뿐만 아니라 리스크 대비 수익률(Sharpe Ratio)을 분석
정책 업데이트 RL 엔진이 DecisionBlender의 가중치를 최적으로 조정

에이전트 헬스케어 (Lifeline)

비정상적인 시장 변동이나 시스템 오류를 감지하면 **Lifeline 에이전트**가 출동합니다.

  • API 세션 복구: 연결 끊김 감지 시 세션을 자동으로 재생성합니다.
  • 로직 자가 수정: 지속적 실패 발생 시 분석 대기 시간을 조정하거나 안전 모드로 전환합니다.
  • 로그 기반 진단: 에러 로그를 LLM이 분석하여 개발자에게 패치를 제안합니다.

데이터베이스 명세 (Database)

Supabase를 활용한 투명한 이력 관리 체계입니다.

테이블명 용도
decisions 모든 매매 판단 근거와 AI 분석 내용 기록
execution_logs 실제 주문 체결 결과 및 거래소 응답 데이터
system_health_logs 자가 치유 활동 및 시스템 상태 이력
